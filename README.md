## 轻量云服务器和 ECS 有什么区别，谁适合买

轻量应用服务器把常用基础云服务打包成固定套餐，控制台里防火墙规则、快照备份、远程连接都能在网页上直接操作，配合预装镜像点几下就能跑起一个网站；ECS 则是配置灵活、可弹性伸缩的标准云服务器，适合高并发、数据库密集型或需要自定义网络架构的业务。前者省心，后者自由，价格上轻量明显更低。

几个实际差异值得记住：

- 轻量应用服务器仅提供包年包月计费，按量付费这一档直接不存在；
- 轻量服务器不支持弹性伸缩，业务增长时需要提前规划迁移，官方提供了轻量服务器之间、轻量迁 ECS、ECS 迁轻量的完整迁移文档，不会被锁死；
- 如果你明确知道未来一年业务会快速膨胀，起步就选 ECS 更省事；反之，起步阶段选轻量，省钱且管理成本低。

### 200M 峰值带宽的真实含义

200M 是限峰值带宽，即带宽上限，官方明确它不作为业务承诺指标——业务高峰期资源争抢时，公网带宽可能受到限制。跑普通网站、部署应用、开发测试，体验基本没问题；如果你的业务要求「任何时刻都保证 200M 稳定输出」，那应该去看 ECS 的固定带宽方案，轻量服务器不适合这种诉求。

内地访问海外节点还有一层延迟问题。官方文档明确：非中国内地地域提供国际带宽，从中国内地访问会有较大延迟。第三方整理的信息显示，香港节点里移动和联通是直连线路，电信走日本方向，所以电信用户晚高峰的体验可能比白天差一点。综合来看，香港仍是海外节点中对内地用户最友好的一个，但如果你的用户全在内地，优先选内地地域并完成备案，体验更好。

## 购买流程，以及四个容易踩的坑

购买本身不复杂：登录轻量应用服务器控制台，单击「创建服务器」，依次选实例规格族、套餐、镜像、地域、数量和时长，付款后等服务器状态从「准备中」变成「运行中」就完成了。真正容易出问题的是下面四个细节，都属于买前一分钟就能确认、买后才发现要命的事。

**1. 地域买定离手。** 服务器创建后不支持更换地域，选错只能退款重买。判断标准就一条：用户在哪里，服务器放哪里。先想清楚目标用户的位置再点付款。

**2. Windows 镜像要配大系统盘。** 官方要求创建 Windows 镜像实例必须选择系统盘大于 40GiB 的套餐。选小了购买页过不去，提前知道能省一轮重选。

**3. 自动续费默认开启。** 时长支持月付 1/3/6 个月、年付 1/2/3 年，默认启用自动续费，避免忘续费导致业务中断。不想自动续费，付款后记得去控制台关掉；月付的续费周期是 1 个月，年付是 1 年。

**4. 新服务器没有初始密码。** 官方 FAQ 明确新创建的轻量应用服务器没有初始密码，首次使用需要先设置密码再登录，或通过 Workbench、VNC 等方式远程连接。卡在登录这一步时，别急着怀疑机器有问题。
